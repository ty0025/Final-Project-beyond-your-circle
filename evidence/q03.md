## 2. Rules (deterministic, written in the `app/discover.py` docstring)

| Rule | Implementation |
|---|---|
| This week | 7 calendar days from today 00:00 (America/New_York), i.e. `[today 00:00, day 8 00:00)`; the page shows concrete dates, e.g. "Sat Oct 24 – Fri Oct 30 (next 7 days)" |
| Later opportunities | Single-date events starting after day 8 00:00 |
| Ongoing community/programs | `program` and `community`; a program shows the next session that is **still open** (source status, e.g. page shows "Register"), with a "Session this week" marker when the session falls this week; programs are not split into separate events |
| Date not stated | Events with no readable date are listed separately as "Date not stated" and never enter this week |
| Expiry | Hidden if there is an end time and it has passed; with no end time, kept until the end of that day; hidden if all registered-date sessions of a program are past; hidden count is shown |
| Dedup | Same normalized URL → keep the latest collection; events with the same "normalized title + same day" → merged into one card with "also listed at" |
| Known ineligible (hidden with reason) | Page explicitly says "undergraduates only / faculty only …"; all later sessions of a program are "Registration closed"; event states full/closed; the registration deadline stated on the page has passed |
| Eligibility | "Stated as open" (e.g. No coding experience is necessary) is separated from "Check before you go (not confirmed for you)" (age, prerequisites, bring a laptop, capacity, etc.); if neither exists, shows "Who can join: not stated on the page" |
| Participation-mode filter | Known mismatches (e.g. Online when In person is selected) are hidden; items with unstated format are kept with the note "the page does not say online or in person" |
| Registration | Only the original registration page link is given, with "A registration link does not guarantee a spot. Registration happens on the organizer's site."; no auto-registration |
| Data status | Each source shows cached / snapshot / unavailable, collection time (ET), and the latest refresh result; a failed refresh shows the failure time and error type, and keeps showing the last data with its collection time |
| Not posing as AI | The top of the page says "Deterministic browsing of collected public pages (keyword filters). Not an AI recommendation."; matches only show "Keyword match: …" |
