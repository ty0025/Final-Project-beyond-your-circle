## 2. 规则（确定性，写在 `app/discover.py` 文档字符串中）

| 规则 | 实现 |
|---|---|
| 本周 | 从今天 00:00（America/New_York）起的 7 个自然日，即 `[今天 00:00, 第 8 天 00:00)`；页面显示具体日期，如“Sat Oct 24 – Fri Oct 30 (next 7 days)” |
| 后续机会 | 单日期活动开始于第 8 天 00:00 之后 |
| 长期社群/持续项目 | `program` 与 `community`；项目显示下一场**仍开放**的场次（原文状态，如 page shows “Register”），场次在本周时加“Session this week”标记；项目不拆成独立活动 |
| 日期不明 | 无可读日期的活动单列“Date not stated”，永不进入本周 |
| 过期 | 有结束时间且已结束则隐藏；无结束时间的保留到当天结束；项目所有已注日期场次都已过去则隐藏；隐藏数量显示 |
| 去重 | 规范化 URL 相同 → 保留最新收集；活动“标题规范化 + 同一天”相同 → 合并为一张卡并记“also listed at” |
| 已知不满足（隐藏并说明原因） | 页面明确写“undergraduates only / faculty only …”；项目所有后续场次都“Registration closed”；活动写明已满/关闭；页面写的报名截止日已过 |
| 资格 | “Stated as open”（如 No coding experience is necessary）与“Check before you go (not confirmed for you)”（年龄、先修、带电脑、容量等）分开；都没有时显示“Who can join: not stated on the page” |
| 参与方式筛选 | 已知不符（例如选 In person 时的 Online）隐藏；格式未写明的保留并提示“页面没有说明线上或线下” |
| 报名 | 只给出原始报名页链接，并写明“A registration link does not guarantee a spot. Registration happens on the organizer's site.”；不自动报名 |
| 数据状态 | 每个来源显示 cached / snapshot / unavailable、收集时间（ET）、最近一次刷新结果；刷新失败显示失败时间、错误类型，并继续显示上次数据及其收集时间 |
| 不冒充 AI | 页面顶部写明“Deterministic browsing of collected public pages (keyword filters). Not an AI recommendation.”；匹配只显示“Keyword match: …” |

| 冷却 | 5 分钟内再次点击：429，提示“Sources were refreshed at … the next refresh is possible in 274 s”，未发请求 |

验证中发现并修复的问题：① 刷新完成后的结果提示被随后的列表重载清空 → 改为重载后再显示；② 网络中断时 robots.txt 读不到，页面错误被误报为 `robots_disallow` → 改为报告真实的 `network`；③ 线上活动同时显示“Where: Online”和“location 未写明” → 线上活动不再把地点列为缺失。
