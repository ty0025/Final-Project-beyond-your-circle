## C. 费率与规模化成本

**费率来源**：Lecture 11 slides（https://zlisto.github.io/mgt_409_fa26/lectures/slides/lec11-slides.html，2026-10-26 重新读取）：gpt-6-luna input $0.10、cached $0.01、cache write $0.125、output $0.50 / 1M tokens；`input_tokens` = “total tokens you sent in”；reasoning tokens “count toward output”。课程未明文写 cached/cache write 是否包含在 input 内；19 + 9 行真实数据全部满足 cached + write ≤ input，且按“包含”计价复算与账本一致。

**缓存区分**：应用层无结果缓存；Portkey 响应缓存每次强制刷新（不会回放旧 usage）；提供方提示词缓存（30 分钟）是唯一生效的缓存，体现为 cached / cache write tokens。

**成本构成**：guard 1 次 + matcher 约 3 次（含在每次运行费用中）；验证器是代码，$0；采集刷新不调用模型，模型费用 $0，由所有用户共享；重试/失败尝试在这 5 次中为 0，若发生会入账但费用记为未知（null）。
