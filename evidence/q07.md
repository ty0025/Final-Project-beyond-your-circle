## 4. 局限（如实保留）

- DNS 重绑定：没有按解析后的 IP 检查；风险由固定主机名 + TLS 主机名校验限制。未验证。
- 恶意页面的文字会被模型看到（标记 + spotlight + 安全提示），但不会被删除；它是否被推荐取决于模型与验证器，本次真实运行未推荐。若真实来源页面被篡改，卡片仍会显示该页面自己的链接（来自采集器，不来自页面正文或模型）。
- 页面原文中的 URL 以纯文本保存在卡片数据中（不渲染为链接）；模型文字中不带查询串的站外 URL 不会被删除，只是不成为链接。
- 规则筛查只认英文措辞；改写过的攻击依赖 LLM guard（模型）判断，guard 故障时放行（fail-open），只剩规则筛查。
- 取消或超时那一刻正在进行的模型调用不入账（费用为下限）；`LLM_MAX_RETRIES=1` 下，触到调用上限后最多再有 1 次重试尝试。
- 不含 canary 的系统提示泄露无法由代码拦截。
- `style-src 'unsafe-inline'` 仍保留。
- 真实红队样本量小（3 次）、合成页面、仅对 2026-10-25 的 gpt-6-luna/Portkey 有效。
