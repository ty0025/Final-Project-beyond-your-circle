## 2. 实现位置

| 文件 | 作用 |
|---|---|
| `app/collect/fetch.py` | `BoundedFetcher`：只允许 HTTPS + 来源允许名单主机；拒绝带用户名/非 443 端口；读取并遵守 robots.txt（200 解析、4xx 视为允许、其他视为全禁）；每主机间隔 ≥ `min_delay_s` 且遵守 robots `Crawl-delay`（上限 15 s）；单请求超时 15 s（连接 5 s）、流式读取上限 2 MB、每次刷新页数上限、最多 3 次重定向且每跳重新检查允许名单；只接受 html/xml/text |
| `app/collect/records.py` | 统一记录 `Record`（event / program / community）与 `Session`、`Evidence`；`missing` 自动列出缺失关键字段 |

| `app/collect/store.py` | 有界刷新、最后成功记录持久化、部分失败延续、cached/snapshot/unavailable 回退、离线 `reparse_cached`、`save_snapshot` |
| `scripts/collect.py` | CLI：`refresh` / `status` / `show` / `snapshot` / `reparse` / `sources` |
| `data/snapshots/caw-photo.json`、`ycgs-events.json` | **提交的真实小样本**（固定快照，含请求日志与 robots 结论） |
| `tests/test_collect.py`、`tests/fixtures/collect/*.html` | 24 个离线测试；7 个夹具是真实页面的裁剪副本（首行注明 URL 与抓取时间） |
| `tests/conftest.py` | 新增自动夹具 `no_real_network`：测试中采集器一旦试图真实联网即报错 |

## 3. 安全与边界

- 采集器使用**独立的** `httpx.Client(trust_env=False, follow_redirects=False)`：不带任何 API key、不带 Authorization、不读环境代理或 `.netrc`、不存 cookie。测试 `test_requests_carry_no_api_key_and_honour_crawl_delay` 检查每个请求头都不含 key/`authorization`/`portkey`。
- 不抓取私人内容：无登录、无表单提交、无 YaleConnect 会员页、无 Slack/邮件。
- 没有引入任何付费搜索或额外 API key（符合 C-12 / I-04）。
- 网页内容只作为数据：本题解析器只做模式匹配，不把页面文字交给模型；后续交给 agent 时须走 `untrusted_output=True` 与 spotlight（问题1 §4.2 第 8 条）。

## 4. 统一记录与“未知”规则

- 每条记录保留：`url`（原始详情页）、`publisher`、`organizer`、`collected_at`（该页抓取的 UTC 时间）、`timezone=America/New_York`、`date_text`（原文日期/学期）、`start`/`end` 或 `sessions[]`、`format`+`format_text`、`location_text`、`eligibility_texts`、`cost_text`、`registration_url`/`registration_text`、`capacity_text`、`summary`、`evidence[]`（字段 + 原文 + 页面位置）、`missing[]`、`warnings[]`。
- 未写明 = `null` 并列入 `missing`；**不推断为免费、不限名额或人人可参加**。报名链接存在只记为链接，不表示有余位；“Registration closed/Register”按原文保存。
- `kind`：单次带日期的活动页 = `event`；课程/练习系列 = `program`，其各场日期留在 `sessions` 内，**不拆成独立活动**；时间写“flexible”的场次不赋日期。

## 7. 失败与回退（全部为**模拟**故障，`httpx.MockTransport`）

| 测试 | 证明 |
|---|---|
| `test_network_failure_keeps_and_serves_last_success` | 模拟断网：返回 `cached`、原 `collected_at`、相同记录；缓存文件字节不变；状态 `failed` + `network` |
| `test_partial_failure_carries_previous_record_forward` | 模拟单页 503：状态 `partial`，失败页沿用上次记录（含其原抓取时间） |
| `test_empty_listing_does_not_erase_previous_records` | 列表为空：状态 `empty`，上次成功记录保留 |
| `test_without_cache_falls_back_to_committed_snapshot_then_unavailable` | 无本机缓存时用提交快照（`snapshot`，带日期）；都没有时 `unavailable` + `failed`（“无数据”，不是“无活动”） |
| `test_robots_txt_is_obeyed`（3 例） | `Disallow: /`（如 events.yale.edu）→ 拒绝；404 → 允许；503 → 拒绝 |
| `test_redirect_off_the_allowlist_is_blocked_and_allowed_redirect_followed` | 跳到非允许主机被拦；站内相对跳转被跟随 |
| `test_size_page_and_content_type_caps` | 超大小、非 HTML（PDF）、超页数均被拦 |
| `test_only_https_allowlisted_urls_are_requested` | http、外站、带用户名的 URL 一个请求都不发 |

真实运行中未出现网络失败；回退能力目前只由上述模拟测试证明（未发生真实故障）。

## 9. 覆盖边界

- caw-photo：摄影系列表页第一页 + 最多 4 个课程页（当前 2 个）。每次刷新约 30 s（遵守 10 s 抓取间隔）。
- ycgs-events：活动列表第一页；按 URL 日期取“今天（America/New_York）至 +75 天”，最多 10 页（当前 9 个）。不翻页。
- 兴趣覆盖：摄影（CAW）、非技术 AI 普及（YCGS 的 GenAI Promptathon、Build A Bot）有真实数据；**运动/观赛目前没有接入来源**（Yale Rec 可读，暂缓）。
- 社群（`kind=community`）尚无记录：YaleConnect 页为空壳；YCGS 的 Drone Hobbyist Gathering 自述为“monthly series”，但本页是单次日期活动，按 `event` 保存，未虚构成社群。
